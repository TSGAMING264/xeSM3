# xeSM3 v0.1.0 — Final Smoke Test

Use the final runtime package generated by `BUILD_FINAL_RELEASE_X86.cmd`.

1. Copy `dbghelp.dll`, `xeSM3.dll`, `xeSM3.ini`, and `Mods` beside `Game.exe`.
2. Boot the game with no mods enabled. Confirm normal startup/gameplay.
3. Confirm the default Debug Xbox PostFX route looks normal.
4. Alt+Tab out and back at least five times, including one 10–20 second desktop stay. Confirm no crash and normal PostFX after return.
5. Enable one normal loose-resource mod with `Mod Name=100`; confirm it loads.
6. Set the same mod to `0`; confirm it does not load.
7. Confirm a value other than `0` or `100` is not treated as a valid public toggle.
8. Test one known-good WRAP resource through a supported route.
9. Confirm malformed WRAP input fails closed rather than crashing or corrupting a pack.
10. Confirm no example is auto-enabled.
11. Confirm the public Release does not create persistent RaimiHook/PostFX/resource-research logs.

Release PASS requires all eleven checks.

## WoS external-MAT test
For this test branch, also load one Blender-generated WRAP MESH whose material field is zero and whose WRAP contains an external `MAT + hash + target` entry. Confirm xeSM3 resolves the material and the model renders without falling back to the legacy serialized-material path.
